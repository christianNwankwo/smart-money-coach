# Smart Money Coach

Financial calculators that show their arithmetic. Everything runs in the browser,
nothing is uploaded, and the site is a folder of static HTML.

```bash
npm install
npm run dev        # US market, http://localhost:3000
npm run build:ng   # Nigeria build
npm test
```

**See [`PROJECT.md`](./PROJECT.md)** for the current state, architecture, the
market system, testing, decisions and known gaps.
